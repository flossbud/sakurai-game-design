# 018 · Clarity vs. Style

**Category:** UI · [Video](https://www.youtube.com/watch?v=UjW_TTNtXEM) · [Transcript](../transcripts/018-clarity-vs-style.md)

## In one sentence
Treat clarity and style in UI as a trade-off you settle per game: organize menus like a tidy drawer, fit the style to your game's content and setting, and make things as user-friendly as you can.

## Key ideas
- In games, "UI" means on-screen display elements like menus and numbers (you could count the controller, but he leaves it out). Clarity and style are "arguably contradictory ideals," and what counts as "stylish" depends on who you ask.
- He considers the Persona series to have "the most stylish UI out there," but it isn't clean or well organized. At a glance it can be hard to parse, even overwhelming. Still, if Persona 5 had used traditional menus just for readability, "No one wants that, right?"
- "A game's UI is like a drawer. When you pull it open, you want things to be organized in a sensible way." How much is crammed into those drawers varies a lot between games.
- "Clear UI doesn't always mean good UI, or vice-versa." It depends on what each title demands. His own games are so packed with features that he often needs "drawers on top of drawers," which he calls "a constant struggle."
- Crafting games leave players "drowning in materials," which is also a UI problem. In Minecraft, many players build warehouses, which is almost like making their own folders for items.
- Each menu has key design points: visual guidance, the size of display elements, window hierarchy, brightness and saturation, and choosing a suitable typeface, among others.
- There's no single right answer. Keep the game's content and setting in mind, and make things more user-friendly where you can.

## Do this
- Decide early where your game sits between clarity and style, based on its content and setting. A strongly stylized game can justify a bolder menu.
- Organize menus like a drawer: group related items sensibly, and plan nested windows (a window hierarchy) when the content is large.
- Review every menu for visual guidance, element size, window hierarchy, brightness and saturation, and typeface.
- If players will collect huge numbers of items, design how they'll sort and find them. Minecraft players end up building warehouses as makeshift folders.
- Once the style is set, still improve usability wherever it doesn't break that style.

## Avoid
- Assuming the clearest UI is automatically the best UI.
- Swapping a game's signature stylish UI for generic menus purely for readability.

## Examples from the episode
- **Persona series / Persona 5 — menus:** in his view the most stylish UI out there, but hard to parse; traditional menus would lose what makes it appealing.
- **Minecraft — item storage:** players build warehouses, almost like their own folders for items.
- **His own games:** so feature-packed they need "drawers on top of drawers."
