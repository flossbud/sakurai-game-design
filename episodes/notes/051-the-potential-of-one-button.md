# 051 · The Potential of One Button

**Category:** Planning & Game Design · [Video](https://www.youtube.com/watch?v=tafG03n89MY) · [Transcript](../transcripts/051-the-potential-of-one-button.md)

## In one sentence
Make the controls fit the gameplay: one button can carry tapping, timing, reaction and hold-and-release games, so add an input only when it improves how the game feels.

## Key ideas
- Sakurai made one-button minigames in Kirby's Adventure and Kirby Super Star. One-button games fall into four categories: rapid tapping, timing-based, reaction-based and alternating.
- **Rapid tapping** tests how fast you can press. Some players are naturally better at it, and it's tiring, so it has fallen out of fashion.
- **Timing-based** games ask you to press or release at a specific moment: release when the crane is in position in Crane Fever. Megaton Punch uses different visual cues but works the same way.
- **Reaction-based** games ask you to press as fast as possible after a signal (Quick Draw, multiplayer Samurai Kirby). They test reflexes, but they also allow push and pull, because players can fake each other out, for example by making the "kah!" signal sound with their mouths.
- **Alternating** games are about when to hold and when to release: in Egg Catcher you hold to catch eggs and release to avoid bombs. A game where you only hold the button is hard to find game essence in; these days holding is more often used for confirmation.
- One button can do a lot, and pairing it with other controls can do more. Whatever you design, consider how each addition will feel; the simplest approach often plays best.

## Do this
- Before adding an input, decide which of the four patterns (tap speed, timed press or release, reaction to a signal, hold versus release) your core action uses, and check whether one button already covers it.
- In head-to-head reaction games, make the start signal something opponents can feint, so the game has push and pull as well as reflexes.
- If the core action is holding, give players a reason to let go (hold to collect good items, release to dodge hazards), because holding alone has little game essence.
- Don't build a core mechanic on rapid tapping: it tires players and rewards natural tapping speed over skill.
- For every control you consider adding, try it and judge how it feels to the player, not whether it's possible.

## Avoid
- Rapid-tapping mechanics, which are tiring and favor players who happen to tap fast.
- Hold-only mechanics with no decision about when to release.
- Adding features just because you can.

## Examples from the episode
- **Kirby minigames — Crane Fever:** release the button when the crane lines up with the plushie (timing).
- **Kirby minigames — Megaton Punch:** different visual cues, same timing principle.
- **Kirby minigames — Quick Draw / Samurai Kirby:** press on the signal; in multiplayer, players fake each other out.
- **Kirby minigames — Egg Catcher:** hold to catch eggs, release to avoid bombs (alternating).

## Quote
