# 137 · Staying Organized with Hierarchical Outlines

**Category:** Planning & Game Design · [Video](https://www.youtube.com/watch?v=ZzCfzwe23kw) · [Transcript](../transcripts/137-staying-organized-with-hierarchical-outlines.md)

## In one sentence
Keep your ideas and specs in a collapsible hierarchical outline (heading, subheading, detail) so they stay clean and easy to reorganize, and tidy the outline before anyone else sees it.

## Key ideas
- A hierarchical outline manages text in tiers, like folders: click a heading to see what's inside, then a subheading to go a level deeper. Sakurai's demo outline is structured the same way as Smash Ultimate's main menu.
- For specs, put each fighter's name at the top level, list their special moves under it, and write each move's spec inside. Collapsing keeps the specs "clean and simple," and items can be reorganized freely.
- The feature is built into Microsoft Word (View → Outline), yet many of his team members have never heard of it. He has used hierarchical outlines since about 1993, when he was issued a Macintosh at work, and "practically can't live without it."
- He mostly uses outlines to compile his own ideas. If others will read the outline, clean it up first, especially since design documents usually end up on a shared company server.
- He planned the categories of this channel in a hierarchical outline.

## Do this
- Switch your design doc to an outline view (in Microsoft Word: View → Outline) and write in tiers, e.g., fighter name → each special move → that move's spec.
- Mirror the game's own structure in the outline (e.g., one top-level heading per main-menu item) so the document maps directly onto the product.
- Collapse everything except the section you're working on, and drag whole headings around when the structure changes, instead of cutting and pasting loose text.
- Use the outline as your private idea store, and do a cleanup pass before it goes onto the shared server for teammates.

## Avoid
- Posting your raw personal outline to the shared server as a design document without cleaning it up.

## Examples from the episode
- **Smash Bros. Ultimate — main menu:** the demo outline mirrors the menu's structure.
- **Fighter special-move specs:** fighter → special moves → spec text.
- **This channel:** its categories were planned in a hierarchical outline.
