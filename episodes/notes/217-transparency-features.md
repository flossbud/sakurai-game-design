# 217 · Transparency Features

**Category:** Programming & Tech · [Video](https://www.youtube.com/watch?v=Ie5wG3LlBNs) · [Transcript](../transcripts/217-transparency-features.md)

## In one sentence
Add developer-mode tools that make chosen parts of a model translucent or invisible, and that toggle each display element on or off, so animations and screens can be checked without obstruction.

## Key ideas
- Smash Bros. Ultimate's developer mode lets the team pick parts of a fighter's model, or the whole model, and make them translucent or remove them entirely. That makes it possible to check each fighter's animations thoroughly.
- On a caped character, the cape hides the poses. The team used to work around this by scaling the cape or removing it from the model. Making it transparent in developer mode proved much handier.
- The feature also helps with checks done outside the dev team.
- Sakurai visited a 3D fighting game developer whose tools could disable clothes and swaying objects. It didn't look good, but it made the animations easy to see.
- Implementing the transparency feature "didn't take long at all." He shows the first screenshot taken with it, along with other shots it made possible.
- A more common feature is a toggle for each display element, which he calls "another must-have!" The team used it often.
- The mode is for developers only, but he highly recommends adding transparency features.

## Do this
- Add a dev-mode option that makes any selected part of a model, or the whole model, translucent or hidden.
- Use it to review poses hidden by capes, clothes or swaying parts, instead of scaling or deleting those parts from the model.
- Add on/off toggles for each display element so you can isolate exactly what you are checking.
- Make these view options available to the people who review your animations outside the dev team.

## Avoid
- Editing the model itself, by scaling or removing the cape, just to inspect an animation.

## Examples from the episode
- **Super Smash Bros. Ultimate — caped fighters:** transparency made poses visible that the cape used to hide.
- **A 3D fighting game developer's office:** its tools could disable clothes and swaying objects to make animations easy to see.

## Quote
> While this mode is purely for developer use, I highly recommend adding transparency features if possible. (02:03)
