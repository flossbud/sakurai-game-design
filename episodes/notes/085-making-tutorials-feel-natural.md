# 085 · Making Tutorials Feel Natural

**Category:** Planning & Game Design · [Video](https://www.youtube.com/watch?v=Xz53DEwuAcU) · [Transcript](../transcripts/085-making-tutorials-feel-natural.md)

## In one sentence
Teach controls through real challenges woven into the game's progression, not through separate practice stages, so the tutorial never feels like work or slows down the start.

## Key ideas
- A tutorial is a guidebook that teaches new players the controls, and it's a required feature in modern games. He thinks the industry has developed a good feel for them.
- Being thrown into a practice stage to fight dummy opponents used to be common and is less so now. It's better to give players real challenges and let them learn by overcoming them. Players who get straight into the game are more engaged and excited.
- Tutorials have a long history. In an early stage of Donkey Kong Country 3, bananas are arranged to spell out buttons, and pressing them performs the right action, though that may be hard to pick up on.
- Modern side-scrollers often show an on-screen control prompt, and you can only progress by doing the action. Other approaches include messages written on walls, a required button press, or info built into the UI.
- Any visual guide to controls must account for button remapping, which is a pain: button icons have to cover every button the player could use.
- For newly acquired skills, a short movie clip next to the skill description is common. Some games let you try skills before acquiring them, but that may not be worth the labor, and if it has load times, players may not use it at all.
- For movement skills, many games confine the player to a small area and require the skill to get out.
- Anything works as long as players learn the controls, but it's better if learning is fun. Tutorials shouldn't feel like work or slow the opening. Weave them into progression.

## Do this
- Replace practice stages with dummies by early real challenges that can only be overcome with the action you're teaching.
- For each movement skill, build a small enclosed area that the player can only leave by using that skill.
- Make control prompts read the current button mapping, and draw icons for every button a player could map an action to.
- Show a short looping clip of each new skill beside its description in the menu.
- Before building a "try before you unlock" skill preview, check the labor is worth it and that it won't add load times that stop players using it.

## Avoid
- Separate practice stages fighting dummy opponents before the real game starts.
- Control prompts that assume default buttons and break when players remap.
- Tutorials that feel like chores or delay the beginning of the game.

## Examples from the episode
- **Donkey Kong Country 3 — early stage:** bananas laid out to spell button names, teaching through the level itself (though it's easy to miss).
- **Modern side-scrolling action games:** on-screen prompts where performing the action is the only way forward.
- **Skill acquisition screens:** short movie clips beside skill descriptions.

## Quote
> Tutorials shouldn't feel like work, or like they're slowing down the beginning of the game— instead, try to weave them into the game's progression itself. (02:33)
