# 019 · Giving "Weight" to Buttons

**Category:** Design Specifics · [Video](https://www.youtube.com/watch?v=9qzUwoKT9T8) · [Transcript](../transcripts/019-giving-weight-to-buttons.md)

## In one sentence
Use what happens on screen (movement speed, inertia, jump physics, lag, frame rate) to decide how "heavy" or "light" the same physical button feels, and give each character its own distinct weight.

## Key ideas
- The same physical button can feel "lighter" or "heavier" depending on how the game is presented and designed. He doesn't mean mechanical resistance like the PS5 DualSense's. The effect is harder to notice with an analog stick or in 3D, but on an NES control pad, moving a character feels radically different from game to game.
- Moving slowly or quickly changes how buttons feel, and so do inertia, jump physics, lag and frame rate. "Even with the same button presses, the response you see on-screen can make them feel so very different."
- He calls this "a powerful tool in a game maker's arsenal."
- Games link a person with a computer. The player takes in information through eyes and ears and sends it back through hand input. You'd assume both directions are one-way, yet "somehow, you can feel feedback with your hands."
- Smash Bros. fighters differ in movement speed, vulnerability and animation flair. That creates the "push and pull" of a fun versus match and makes characters feel "wildly different in your hands."
- Every console's analog stick is slightly different, so tilt sensitivity, "the lowest value at which stick tilt is detected," has to be configured for each one.

## Do this
- Decide the intended "weight" of each character, then tune movement speed, inertia and jump physics to produce it. Compare characters side by side with identical inputs.
- Count lag and frame rate as part of feel. Both change how heavy a button seems.
- Make playable characters distinct through movement speed, vulnerability and animation flair, so each one feels different in the hands.
- Set analog stick tilt sensitivity (the lowest tilt that registers) separately for each console or controller you support.

## Avoid
- Assuming feel comes only from the physical hardware and ignoring the on-screen response.
- Using one stick-sensitivity value across different consoles.

## Examples from the episode
- **NES control pad games:** the same D-pad makes movement feel radically different from game to game.
- **PS5 DualSense:** mechanical resistance, which is not the kind of weight he means.
- **Super Smash Bros. — fighter differences:** movement speed, vulnerability and animation flair create push and pull and a distinct feel for each fighter.
