[00:22](https://youtu.be/kcYDrtRvuKg?t=22) Many effects are achieved through a process called additive blending. Let's start, for example, by drawing some effects for an explosion or flash. Using additive blending, we then layer these elements onto the background.

[00:37](https://youtu.be/kcYDrtRvuKg?t=37) In doing so, each element's colors are “added" to the background, bringing them closer to white. This is different from translucency, where the colors would move closer to those of the original elements.

[00:48](https://youtu.be/kcYDrtRvuKg?t=48) Keep adding layer upon layer, and you'll end up with something suitable. Don't let additive blending do all the work for you! It's good for achieving decent results using relatively simple visuals— but that's it.
