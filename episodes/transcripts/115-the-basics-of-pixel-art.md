I also drew a good few enemy characters and backgrounds, some of which were reused when we made the next Kirby game for the NES. Modern games let you employ an immense array of colors, so this information may not be too useful anymore, but I'd like to touch on some pixel art techniques I used on the Game Boy and NES, which had few colors available.

[00:33](https://youtu.be/NDno0U5UxSI?t=33) On the NES and Game Boy, we often used sprites comprised of 16x16 pixels. A sprite is a unit of measurement used in game art. Using sprites, you can move game art smoothly on-screen. Needless to say, Kirby himself is 16x16 pixels.

[00:51](https://youtu.be/NDno0U5UxSI?t=51) That said, when you're drawing a circle at this size, a 15x15 circle looks better than a 16x16 one. Even though it's smaller? Well, let's take a look.

[01:03](https://youtu.be/NDno0U5UxSI?t=63) Here's a 16x16 circle. And here's a 15x15 one. If you compare them, you'll see the 15x15 one is more of a true circle. That's because it has clear median lines.

[01:18](https://youtu.be/NDno0U5UxSI?t=78) If you're building something in a crafting game with broad units, I recommend using odd-numbered sides to give it clearer median lines. It's just easier that way. Let's say you only have two colors available: black and white.

[01:32](https://youtu.be/NDno0U5UxSI?t=92) If you want to add texture... You might draw just an outline, then add a highlight to create a bubble. Applying a mesh will make it look more flat than round. And notice how simply flipping the mesh can change the feel.

[01:48](https://youtu.be/NDno0U5UxSI?t=108) You could make it completely black, then add a highlight to create a cannonball. Even with minimal shapes like this, you can still show plenty of range. With just one more color, we're able to soften the edges. This technique is essential for more precise details.

[02:05](https://youtu.be/NDno0U5UxSI?t=125) With a reflective material, you can use that third color to show the reflection of the floor. And when we smooth the edges, it starts looking pretty nice. Though that does depend on your background color.
